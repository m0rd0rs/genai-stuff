# genai-playground

> "Sharing is good." — *m0rd0r*

A raw, zero-fluff collection of Generative AI scripts, prompt pipelines, LLM utilities, and orchestration experiments. No massive, bloated enterprise frameworks here—just clean scripts, structured configs, and direct API/local model interactions designed to get things done from the command line.

## Why this repo?

Most GenAI tools out there are wrapped in heavy abstractions or hidden behind black-box GUIs. This project serves as my personal lab notebook and utility belt—focusing on raw performance, API efficiency, local inference setups (Ollama, Hugging Face, vLLM), and lightweight automation scripts that don't require spinning up a 500MB node dependency chain.
