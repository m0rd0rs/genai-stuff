# Sudoku solver

> "Sharing is good." — *m0rd0r*

Wanted to test how bad is Codex in generating a recursive solver for Sudoku with a frontend. Did not get disappointed actually.

## Why?

Most GenAI tools out there are supposed to suck at generating UIs even with very detailed prompts. And I love sudoku, so why not?

## 🛠️ What's Inside

Sudoku solver with CLI and TUI. Both generated by Codex. Prompts only. No human interaction.  Sudoku TUI      Arrows move  1-9 enter  Del clears  Enter resolves  q quits
